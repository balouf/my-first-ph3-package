## Quickstart

Install My First PH3 Package:

```console
$ pip install my-first-ph3-package
```

Use My First PH3 Package in a Python project:

```pycon
>>> from my_first_ph3_package import MyClass1
>>> my_object = MyClass1(a=5, b=3)
>>> my_object.addition()
8
```
